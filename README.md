# 📝 Examen HTML y CSS

Repositorio correspondiente a la evaluación práctica de **HTML y CSS**, centrado en el diseño, estructuración y estilización de páginas web utilizando buenas prácticas de desarrollo web frontend.

---

## 🚀 Tecnologías Utilizadas

* **HTML5:** Estructura semántica del contenido de la página web.
* **CSS3:** Estilos visuales, diseño, maquetación y propiedades de presentación.

---

## 📂 Estructura del Proyecto

La estructura del repositorio se organiza de la siguiente manera:

```text
Examen_html_y_css/
│
├── index.html         # Página principal del proyecto
├── css/
│   └── styles.css     # Hoja de estilos principal
└── assets/            # Recursos gráficos (imágenes, iconos, etc.) - Opcional
